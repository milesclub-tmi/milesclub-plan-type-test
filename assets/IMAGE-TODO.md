# 이미지 작업 목록

아래 파일명 그대로 PNG를 넣으면 페이지에서 자동으로 표시됩니다.

## 시작 화면

- `start/start.png`
  - 위치: 시작 화면 상단 대표 이미지
  - 내용: 요금제 성향 테스트를 시작하는 가벼운 대표 비주얼

## 질문 화면

- `questions/q1.png`
  - 질문: 약속 시간까지 20분, 지하철에 앉았다. 내 폰에서는?
  - 추천 장면: 지하철에서 휴대폰을 보는 상황
- `questions/q2.png`
  - 질문: 월말 데이터 알림이 떴다. 가장 가까운 반응은?
  - 추천 장면: 데이터 잔량 알림 또는 속도제한 경고
- `questions/q3.png`
  - 질문: 요금제 광고를 봤다. 가장 먼저 눈에 들어오는 문구는?
  - 추천 장면: 요금제 광고 배너를 보는 상황
- `questions/q4.png`
  - 질문: 친구가 "이 요금제 더 싸대" 링크를 보냈다.
  - 추천 장면: 채팅방에 공유된 요금제 링크
- `questions/q5.png`
  - 질문: 배터리 20% 남았는데도 쉽게 포기 못 하는 앱은?
  - 추천 장면: 배터리 부족 상태에서 앱을 계속 쓰는 상황
- `questions/q6.png`
  - 질문: 요금제가 같은 가격이라면, 더 끌리는 덤은?
  - 추천 장면: 멤버십, 쿠폰, 구독, 로밍 혜택 중 고르는 상황
- `questions/q7.png`
  - 질문: 누가 "너 요금제 이름 뭐야?"라고 물으면?
  - 추천 장면: 내 요금제를 떠올리거나 통신사 앱을 확인하는 상황
- `questions/q8.png`
  - 질문: 진짜 바꿀까 하다가 멈칫하는 순간은?
  - 추천 장면: 유심, 번호이동, 개통 절차 앞에서 고민하는 상황

## 권장 사이즈

- 시작 화면: 720 x 380px 이상
- 질문 화면: 720 x 340px 이상
- 결과 화면: 720 x 380px 이상
- 투명 배경 PNG도 가능하고, 자체 배경이 있는 PNG도 가능합니다.
