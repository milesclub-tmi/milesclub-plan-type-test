# 이미지 작업 목록

아래 파일명 그대로 PNG를 넣으면 페이지에서 자동으로 표시됩니다.

## 시작 화면

- `start/start.png`
  - 위치: 시작 화면 상단 대표 이미지
  - 내용: 요금제 성향 테스트를 시작하는 가벼운 대표 비주얼

## 질문 화면

일상 질문 5개 + 통신 질문 3개 구성입니다.
일상 질문 이미지에는 휴대폰·데이터·통신사 요소가 드러나지 않아야 합니다.

- `questions/buffet.png`
  - 질문: 뷔페에 왔다. 첫 접시를 채우는 방식은?
  - 추천 장면: 접시에 음식을 담는 상황
- `questions/luggage.png`
  - 질문: 3박 4일 여행. 캐리어를 싸는 당신은?
  - 추천 장면: 캐리어에 짐을 넣는 상황
- `questions/cafe.png`
  - 질문: 카페에 앉았다. 자리 잡고 가장 먼저 하는 건?
  - 추천 장면: 카페 테이블의 커피와 와이파이 신호
- `questions/binge.png`
  - 질문: 드라마가 재밌다. '다음 화' 버튼 앞에서.
  - 추천 장면: 늦은 밤 화면을 계속 보는 상황
- `questions/promo.png`
  - 질문: 편의점에서 '2+1' 스티커를 봤다.
  - 추천 장면: 행사 상품 앞에서 고민하는 상황
- `questions/cart.png`
  - 질문: 장바구니에 담아둔 물건이 하나 있다.
  - 추천 장면: 장바구니와 가격표
- `questions/applogin.png`
  - 질문: 통신사 앱을 열었는데 비밀번호가 기억나지 않는다.
  - 추천 장면: 로그인 화면 앞에서 막힌 상황
- `questions/friendtip.png`
  - 질문: 친구가 "나 요금제 바꿔서 만원 아꼈어"라고 자랑한다.
  - 추천 장면: 대화 말풍선
