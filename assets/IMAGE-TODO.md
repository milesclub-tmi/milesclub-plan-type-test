# 이미지 작업 목록

아래 파일명 그대로 PNG를 넣으면 페이지에서 자동으로 표시됩니다.

## 시작 화면

- `start/start.png`
  - 위치: 시작 화면 상단 대표 이미지
  - 내용: 요금제 성향 테스트를 시작하는 가벼운 대표 비주얼

## 질문 화면

문항은 통신·요금제를 직접 묻지 않는 일상 질문입니다.
이미지에도 휴대폰·데이터·통신사 요소가 드러나면 결과의 반전이 죽습니다.

- `questions/buffet.png`
  - 질문: 뷔페에 왔다. 첫 접시를 채우는 방식은?
  - 추천 장면: 접시에 음식을 담는 상황
- `questions/luggage.png`
  - 질문: 3박 4일 여행. 캐리어를 싸는 당신은?
  - 추천 장면: 캐리어에 짐을 넣는 상황
- `questions/burger.png`
  - 질문: 햄버거집. 주문할 차례가 돌아왔다.
  - 추천 장면: 햄버거 세트를 고르는 상황
- `questions/binge.png`
  - 질문: 드라마가 재밌다. '다음 화' 버튼 앞에서.
  - 추천 장면: 늦은 밤 화면을 계속 보는 상황
- `questions/promo.png`
  - 질문: 편의점에서 '2+1' 스티커를 봤다.
  - 추천 장면: 행사 상품 앞에서 고민하는 상황
- `questions/cart.png`
  - 질문: 장바구니에 담아둔 물건이 하나 있다.
  - 추천 장면: 장바구니와 가격표
- `questions/fridge.png`
  - 질문: 지금 냉장고 안쪽에 뭐가 있는지 아세요?
  - 추천 장면: 냉장고 문을 열어본 상황
- `questions/queue.png`
  - 질문: 맛집 앞에 40분 줄이 서 있다.
  - 추천 장면: 가게 앞에 늘어선 대기줄

## 권장 사이즈

- 시작 화면: 720 x 380px 이상
- 질문 화면: 720 x 340px 이상
- 결과 화면: 720 x 380px 이상
- 투명 배경 PNG도 가능하고, 자체 배경이 있는 PNG도 가능합니다.
